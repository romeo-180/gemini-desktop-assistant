# 🤖 Gemini Desktop System Agent (Windows & Linux)

Умный голосовой помощник на базе **Google Gemini** в системном трее (возле часов). Запускает программы, очищает систему, анализирует экран и отвечает голосом Светланы.

---

## 🚀 Быстрая установка

### 🪟 Windows 10 / 11
**Способ 1 — Готовый файл (проще всего):**
1. Скачайте **`GeminiAgent-Windows.exe`** в разделе **[Releases](https://github.com/romeo-180/gemini-windows-agent/releases/latest)**.
2. Запустите его двойным кликом. Программа сама добавится в автозапуск и покажет окно для ввода бесплатного API-ключа.

**Способ 2 — Установка одной командой в PowerShell:**
```powershell
irm https://raw.githubusercontent.com/romeo-180/gemini-windows-agent/main/install.ps1 | iex
```

---

### 🐧 Linux (Arch Linux, Ubuntu, Debian, Fedora)
Откройте терминал и вставьте одну команду:
```bash
curl -sSL https://raw.githubusercontent.com/romeo-180/gemini-windows-agent/main/install.sh | bash
```
Скрипт сам определит ваш дистрибутив (`pacman`, `apt` или `dnf`), установит нужные пакеты, добавит ярлык в меню приложений, настроит автозапуск и откроет окно для ввода API-ключа.

*(Либо скачайте портативный файл **`GeminiAgent-Linux`** из раздела **[Releases](https://github.com/romeo-180/gemini-windows-agent/releases/latest)**).*

---

## 🔑 Где взять бесплатный API-ключ?
При первом запуске программа сама покажет окно с кнопкой **«🔑 Получить ключ бесплатно»**. Также его можно создать заранее за 1 минуту:
1. Перейдите на **[Google AI Studio](https://aistudio.google.com/)** под своим Google-аккаунтом.
2. Нажмите синюю кнопку **«Create API key»** (или **«Get API key»**) и скопируйте ключ (начинается на `AIzaSy...`).
3. Вставьте его в появившееся окно программы при запуске.

## 🎙 Основные команды и функции

| Команда / Кнопка | Что делает |
| :--- | :--- |
| **«Запусти ворд» / «Writer»** | Открывает чистый документ LibreOffice Writer |
| **«Запусти эксель» / «Calc»** | Запускает таблицы LibreOffice Calc |
| **«Запусти пдф»** | Открывает системный просмотрщик PDF |
| **«Запусти YouTube / Tabby / Steam»** | Открывает нужное приложение или сайт |
| **«Выключи звук» / «Замолчи»** | Мгновенно отключает голосовую озвучку |
| **«Включи звук»** | Возвращает голосовые ответы Светланы |
| **Кнопка «🧹 Быстрая»** | Очищает Temp, кэши, корзину и разгружает RAM |
| **Кнопка «🔥 Глубокая»** | Удаляет дампы, кэш обновлений и сжимает систему |
| **Кнопка «👁 Экран»** | Делает скриншот и анализирует открытые окна |

### 📊 Мониторинг в трее
* **Наведение мыши на значок:** показывает нагрузку CPU, RAM, VRAM и баланс API.
* **Правый клик по значку:** открывает меню управления и системные показатели.
