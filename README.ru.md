# 🤖 Gemini Desktop System Agent (Windows & Linux)

🌐 **Language / Язык:** [**🇺🇸 English**](README.md) | [**🇷🇺 Русский**](README.ru.md)

Умный голосовой и системный ИИ-помощник на базе **Google Gemini** в системном трее (возле часов). Автоматически находит и запускает **любые установленные на компьютере программы и игры**, очищает систему и оперативную память, видит экран и отвечает живым голосом (автоматически переключаясь между русским и английским).

---

## 🚀 Быстрая установка

### 🪟 Windows 10 / 11
**Способ 1 — Готовый файл (проще всего):**
1. Скачайте **`GeminiAgent-Windows.exe`** в разделе **[Releases](https://github.com/romeo-180/gemini-windows-agent/releases/latest)**.
2. Запустите его двойным кликом. При первом старте выберите язык (**English / Русский**), программа сама добавится в автозапуск и покажет окно для ввода бесплатного API-ключа.

**Способ 2 — Установка одной командой в PowerShell:**
```powershell
irm https://raw.githubusercontent.com/romeo-180/gemini-desktop-assistant/main/install.ps1 | iex
```

---

### 🐧 Linux (Arch Linux, Ubuntu, Debian, Fedora)
Откройте терминал и вставьте одну команду:
```bash
curl -sSL https://raw.githubusercontent.com/romeo-180/gemini-desktop-assistant/main/install.sh | bash
```
Скрипт сам определит ваш дистрибутив (`pacman`, `apt` или `dnf`), установит пакеты, добавит ярлык в меню программ, настроит автозапуск и предложит выбрать язык и ввести API-ключ.

*(Либо скачайте готовый портативный файл **`GeminiAgent-Linux`** в разделе **[Releases](https://github.com/romeo-180/gemini-windows-agent/releases/latest)**).*

## 🔑 Где взять бесплатный API-ключ?
При первом запуске нажмите кнопку **«🔑 Получить ключ бесплатно»** в появившемся окне, либо создайте его за 1 минуту:
1. Зайдите на **[Google AI Studio](https://aistudio.google.com/)** под своим Google-аккаунтом.
2. Нажмите синюю кнопку **«Create API key»** (или **«Get API key»**) и скопируйте ключ (начинается на `AIzaSy...`).
3. Вставьте его в окно программы при запуске.

## ✨ Что умеет ассистент

* **🚀 Запуск ЛЮБЫХ установленных программ, игр и сайтов:**
  Агент сам сканирует все установленные программы и ярлыки на вашем ПК (меню «Пуск», Рабочий стол, игры в Steam, системные приложения). Достаточно сказать или написать название любой программы на компьютере: *«Запусти Discord»*, *«Открой Blender»*, *«Включи Telegram»*, *«Запусти браузер»* или *«Открой YouTube»*.
* **🎙 Голосовое и текстовое общение (кнопка «🎙 Сказать»):**
  Понимает речь и отвечает на **любом языке**, автоматически подбирая голос озвучки (Светлана для русского, Aria для английского).
* **🔇 Управление озвучкой на лету:**
  Команды *«Выключи звук»* / *«Замолчи»* мгновенно переводят ответы в тихий текстовый режим, а *«Включи звук»* возвращает голос.
* **🧹 Быстрая очистка системы (кнопка «🧹 Быстрая» или команда *«Почисти»*):**
  Очищает временные файлы (`Temp`), кэши шейдеров и миниатюр, корзину и выгружает неиспользуемую оперативную память (RAM).
* **🔥 Глубокая очистка системы (кнопка «🔥 Глубокая» или команда *«Глубокая очистка»*):**
  Удаляет системные дампы, очищает кэш пакетов и обновлений (`WinSxS` на Windows / `paccache` и `journalctl` на Linux) и освобождает место на диске.
* **👁 Зрение и анализ экрана (кнопка «👁 Экран»):**
  Делает снимок экрана и анализирует открытые окна, ошибки, код или изображения через Gemini.
* **📊 Мониторинг системы в трее:**
  * **Наведение мыши на значок:** показывает нагрузку CPU, RAM, VRAM и статистику API в реальном времени.
  * **Правый клик по значку:** открывает быстрое меню управления и показатели системы.
